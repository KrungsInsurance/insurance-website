# Persona illustration assets

Created 2026-09-12 for the three-step insurance onboarding. Tool: built-in `image_gen.imagegen`, five independent generation calls (no API/CLI fallback). All five outputs were visually inspected. These are fictional illustrative age avatars; no real customer likeness, gender choice, diagnosis, eligibility or demographic inference is implied.

## Asset contract

All files are 1254 × 1254 PNG, square, white background, matching warm graphite and colored-pencil treatment. Display with `object-fit: contain` to retain the waving hand. The UI should use the age-band label as the input; artwork is decorative and can use empty alt when adjacent to the same label. Originals retained unchanged. No post-generation editing.
